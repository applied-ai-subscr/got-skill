# Fiche de poste (scorecard) — Data Engineer

- Titre : Data Engineer
- Direction : Data & Plateforme, équipe de 6 personnes
- Localisation : Nantes, 2 jours de télétravail par semaine
- Contrat : CDI
- Rémunération : 48 000 à 55 000 € brut annuel selon expérience
- Expérience : 3 ans minimum en ingénierie de données
- Formation : Bac+5 ou expérience équivalente

## Mission
Fiabiliser et industrialiser les pipelines de données qui alimentent les tableaux de bord commerciaux et le scoring client.

## Résultats attendus (12 mois)
- Réduire de 40 % la latence du pipeline de consolidation des ventes (aujourd'hui 6 h).
- Mettre en place des tests de qualité de données sur les 5 flux critiques.
- Documenter le catalogue de données et former 2 analystes à son usage.

## Compétences
Obligatoires : Python, SQL avancé, dbt ou équivalent, orchestration (Airflow ou Dagster), Git.
Appréciées : Snowflake ou BigQuery, Terraform, notions de Kafka.
Comportementales : autonomie, pédagogie, goût pour la documentation.
