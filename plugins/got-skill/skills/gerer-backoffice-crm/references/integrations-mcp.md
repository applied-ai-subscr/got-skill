# Intégrations MCP

## Registre d'entreprises

Chercher par SIREN lorsqu'il est disponible. Sinon, rechercher par raison sociale et départager les résultats avec l'adresse. Avec Pappers ou un registre équivalent, utiliser la recherche puis le détail de l'entreprise sélectionnée.

## CRM

Rechercher une fiche avant toute création. Utiliser l'identifiant natif retourné pour une mise à jour. Avant l'écriture, afficher l'objet, l'identifiant, les champs modifiés et les anciennes et nouvelles valeurs connues.

## Documents

Identifier le modèle et le dossier de destination. Préparer les variables de fusion, signaler celles qui manquent, puis demander confirmation. Restituer uniquement le lien ou l'identifiant réellement retourné.

## Sans connecteur

Produire un tableau de champs ou une charge utile JSON ou CSV compatible. Ne pas simuler l'appel.
